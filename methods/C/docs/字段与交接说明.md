# 预测与掩码嵌入接口

indices/all_samples.csv 中 model_setting、split、sample_id 联合定位。original 对应 results/original，adapter 对应 results/adapter_bf16。固定 train/val/test=700/150/150，种子 42。

| NPZ 字段 | 类型形状 | 含义 |
|---|---|---|
| sample_id | Unicode 标量 | 与文件名和划分 ID 一致 |
| probability | float32 [原图H,原图W] | 前景概率，sigmoid 后双线性还原原图 |
| prediction_mask | uint8 [原图H,原图W] | probability > 0.5，0 背景 1 息肉 |
| mask_embedding | float32 [32,256,256] | mask_decoder.output_upscaling 原始输出，未归一化未去均值 |
| bbox_original | float32 [4] | xyxy 真值紧致框，无扰动 |
| bbox_1024 | float32 [4] | 按宽高缩放到 1024 的 xyxy |
| original_size | int64 [2] | [H,W] |

输入 RGB，三次插值到 1024×1024 后 uint8，再逐图 min-max 为 float32 CHW。GT 灰度 >127。概率双线性插值 align_corners=False，指标在原图按图计算再平均，标准差 ddof=0。

不确定性可由前景概率 p 计算二类熵，处理 0/1 端点。若在 256×256 嵌入网格使用 GT，应明确最近邻缩放标签，不直接用原图坐标索引。范数表 L2 是整个 [32,256,256] 张量范数，不是每像素归一化向量范数。

本批按统一接口提供 probability，未另存原始 logits。PDF 提及掩码 logit，不能把概率冒充原始 logits：现有概率足够计算规定熵和校准指标，但饱和的 0/1 不能精确反推 logits。若下游严格需要原始 logits，应扩展接口另行补导。

numpy.load(path, allow_pickle=False) 读取。scripts/load_export_example.py 提供同一 ID 的两设置示例。
