# 安装与复现

在本包根目录执行，Python 3.10，独立新建虚拟环境。基座和数据已附带，SAM 源码在 vendor，含许可证与来源；其他依赖安装需联网。本次整理没有修改现有环境。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.10.0+cu128 torchvision==0.25.0+cu128 --index-url https://pypi.org/simple --extra-index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r environment/requirements-reproduce.txt
.\.venv\Scripts\python.exe scripts/verify_delivery.py
```

上述 PyTorch 适用于当前 Windows/CUDA，其他硬件安装兼容版本并记录差异。

## 模型实例

```python
from medsam_model import load_medsam
from adapter_model import build_adapter_model, load_adapter_checkpoint
original, device = load_medsam('weights/medsam_vit_b.pth', device='cuda', verify_checksum=True)
original.requires_grad_(False)
adapter, device = build_adapter_model('weights/medsam_vit_b.pth', device='cuda')
load_adapter_checkpoint(adapter, 'checkpoints/adapter_bf16/best.pt')
```

## 重放已保存的续训

```powershell
.\.venv\Scripts\python.exe train_adapter.py --config config/adapter.json --device cuda --resume checkpoints/adapter_fp16_stage/best.pt --epochs 20 --output-dir reproduced/adapter_train --checkpoint-dir reproduced/adapter_checkpoints
```

先完整 BF16 val 重评，再训练 9—20 轮。健康第 8 轮模型、优化器和随机状态已附带。不同硬件软件不保证逐位一致；config/adapter_fp16.json 与 logs/fp16_code_snapshot 仅供追溯，不建议重跑故障流程。
