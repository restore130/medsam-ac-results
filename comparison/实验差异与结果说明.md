# 实验设置与比较注意事项

Linear Probe 与 Adapter 的数据划分和预处理代码一致，20 epoch、batch=1、seed42、AdamW、weight_decay0.01、无随机增强、无学习率调度器。学习率按方法分别为1e-3和5e-4。两者均以完整验证集原图平均 Dice 选最佳权重。

## 损失与数值精度

A 使用 Dice+BCE，smooth=1e-5；C 使用0.5Dice+0.5BCE，smooth=1e-6。相对权重相同，整体尺度和平滑项不同，训练轨迹不能保证一致，不直接比较原始训练loss数值。相关差异不能通过修改配置文件消除，应随结果披露。

A 训练与导出 FP16。C 的有效 Adapter 路径前8轮FP16、健康第8轮恢复后以BF16完成9至20轮，失效旧运行不纳入有效曲线。C原始模型FP16推理，低精度logits先sigmoid；Adapter将logits转float32再sigmoid。保留 C 的异常和恢复说明，不补造缺失运行记录。

A嵌入存储float16，C存储float32。统一读取为float32供分析，但不声称前向精度相同。共同概率字段可计算二类熵和校准；C没有原始logits，A的low_res_logits也不是原图尺寸logits，不直接拼接为同一字段。

## 表征解释

A只训练超网络输出头，所提取output_upscaling嵌入位于其上游，因此预期基本不变；它不代表没有发生输出端学习。实际对照还涉及设备及推理精度差异。不要仅凭不同模型的特征图数值变化推断因果。

## 结果与资源口径

测试Dice：original约0.93618，Linear Probe约0.96159，Adapter约0.96540。此为单划分、单次有效训练与真值框设定，未提供多随机种子或显著性证据。更高Dice不能直接推出更好的校准或更小漂移。

A训练耗时为20个已完成epoch之和，不包括被中断且重跑的不完整轮次。C summary的training_seconds_this_invocation仅指恢复调用，不能当完整20轮总时间。原始模型训练耗时不适用；C没有完整推理峰值显存，保留未记录。完整C资源与历史说明在methods/C/docs/结果与运行记录.md及tables内。
